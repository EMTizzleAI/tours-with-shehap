# Tours with Shehap Salah

Responsive single-page site for private and custom Egypt experiences.

## Editing
The main site is `index.html`. Near the bottom, find `const SITE = {...}`. Tour names, stops, descriptions, WhatsApp numbers, and pre-filled messages are kept there so confirmed pricing, availability, destinations, inclusions, photos, and other real service details can be updated later without redesigning the page.

Current itinerary content is a working draft and should be confirmed with Shehap before representing it as a fixed commercial package.

## Deploy
Designed for GitHub Pages. In repository Settings → Pages, publish from the `main` branch / root.
